# Minetest Server

Репозиторий содержит конфигурацию, моды и базовую структуру мира для развертывания сервера Minetest в Docker. Динамические данные (карты, базы игроков, кэш и логи) исключены через `.gitignore`.

## Экспорт проекта (Создание бэкапа сборки)

Чтобы перенести конфигурацию и моды на другой сервер или сделать чистый снимок сборки без рабочих баз данных, достаточно заархивировать **только скрытую директорию `.git`** из корня проекта. Она уже содержит всю актуальную версию файлов и историю изменений.

Выполните в корне проекта:
```bash
tar -czf bare_git_copy.tgz .git
```

## Развертывание и запуск из архива

1. **Создайте рабочую директорию и перейдите в неё:**
   ```bash
   mkdir minetest-server && cd minetest-server
   ```

2. **Распакуйте архив `bare_git_copy.tgz` в текущую папку:**
   ```bash
   tar -xzf /путь/к/bare_git_copy.tgz
   ```
   *(Проверить наличие скрытой папки `.git` можно командой `ls -la`).*

3. **Восстановите рабочие файлы проекта из Git:**
   ```bash
   git restore .
   ```
   *(Для старых версий Git используйте `git checkout -- .` или `git reset --hard HEAD`).*

4. **Запустите сервер:**
   ```bash
   docker compose up -d
   ```
