# Luanti Server

Репозиторий содержит конфигурацию, моды и базовую структуру мира для развертывания сервера Minetest в Docker. Динамические данные (карты, базы игроков, кэш и логи) исключены через `.gitignore`.

## Развертывание и запуск из архива

1. **Загрузите конфигурацию сервера в свое окружение:**
   ```bash
   git clone https://github.com/Yerk08/luanti-mineclonia
   ```

2. **Настройте конфигурацию сервера под себя:**
   Откройте файл `data/.minetest/main-config/minetest.conf` и проверьте следующие параметры перед первым запуском:
   * **`name`** — укажите свой игровой ник (игрок с этим именем получит права администратора при входе).
   * **`server_address`** — замените домен `petricalc.duckdns.org` на ваш актуальный IP или доменное имя.
   * **`server_name` и `server_description`** — при необходимости измените название и описание сервера для публичного списка.
   * **`server_announce`** — установите `false`, если хотите сделать приватный сервер только для своих и не публиковать его в общем мониторинге.

3. **Запустите сервер:**
   При необходимости отредактируйте `docker-compose.yml` под свои нужды и выполните:
   ```bash
   docker compose up -d
   ```
