# Deadcount

Серверный мод для Luanti/Mineclonia: счётчик смертей и килов онлайн-игроков
с HUD, цветами «команд», режимом заражения и заморозкой. Входит в сборку
Doom-like, но остаётся отдельным модом и не зависит от `doomlike`,
`rifles` или других модов. Клиенту ничего устанавливать не нужно — HUD
рисует сервер.

## Режимы показа

HUD всегда показывает **одну колонку**: либо смерти, либо килы.
Положение HUD фиксированное — справа сверху, **под миникартой**.

```text
/deadcount mode deaths   -- показывать смерти
/deadcount mode kills    -- показывать килы
/deadcount mode none     -- вообще не показывать HUD
/deadcount mode          -- текущий режим
```

`none` не выключает подсчёт: смерти и килы продолжают записываться,
просто HUD скрыт. Режим сохраняется в мире.

Пример HUD в режиме смертей:

```text
Смерти [F] [U 29:59] [Z]
Vasya       7  [C]
Petya       3  [ ]
Timofey     0  [ ]
+2 ещё
```

В режиме килов заголовок меняется на `Килы`, а числа сортируются по килам.

- По умолчанию видно до **10 игроков**; если онлайн больше — последняя
  строка `+N ещё`. Настройка `deadcount_max_rows = 0` показывает всех.
- Ник — фиксированная колонка 18 символов, длинные имена обрезаются `…`.
- `[C]` — игрок в креативе. Цвет `[C]` совпадает с цветом ника.
- `[ ]` — обычный режим; пустая колонка нужна, чтобы строки не прыгали.

### Обозначения в заголовке

| Тег | Значение |
|---|---|
| `[F]` | счётчик заморожен |
| `[F 09:59]` | заморозка начнётся через 9 минут 59 секунд |
| `[U 29:59]` | разморозка через 29 минут 59 секунд |
| `[Z]` | включён режим заражения |

В чате `/deaths` те же состояния пишутся полными словами.

## Цвета и команды

По умолчанию все ники нейтрального цвета (`#E0E0E0`). Игрок может сам
выбрать цвет:

```text
/team red
/team green
/team off
/team list
/team
```

Админ может задать цвет другому игроку, в том числе офлайн:

```text
/deadcount color Vasya blue
/deadcount color Vasya #33AAFF
/deadcount color Vasya off
```

Доступные имена цветов: `red`, `green`, `blue`, `yellow`, `orange`,
`purple`, `cyan`, `pink`, `white`, `gray`. Можно указать свой `#RRGGBB`.
Слишком тёмные цвета отклоняются, чтобы ник не пропадал на фоне.

## Килы

Кил засчитывается, когда игрок умирает от другого игрока.

- **Самоубийство** (в том числе своим взрывом) — не кил.
- **Свой** — игрок с тем же **явно выбранным** цветом. Убийство своего
  не засчитывается.
- **Нейтральные** (без цвета) не считаются одной командой: два игрока
  без цвета могут убивать друг друга, и кил засчитается.
- Разные цвета — разные команды, кил засчитывается.
- Смерти от мобов, падения, лавы и т.п. килов никому не дают.

Пример: два красных и два нейтральных. Красный убивает красного — кила
нет. Нейтральный убивает нейтрального — кил есть. Красный убивает
нейтрального — кил есть.

В режиме заражения зелёный цвет — это **отображение состояния**, а не
выбранная команда. Принадлежность для килов всё равно определяется
цветом, который игрок выбрал через `/team`.

## Заражение

```text
/deadcount infection on
/deadcount infection off
/deadcount infection status
```

Пока режим включён, все игроки с `deaths > 0` отображаются **зелёными**,
даже если у них выбран другой цвет. Свой цвет при этом сохраняется и
вернётся, когда режим выключат или админ сбросит смерти.

- Игрок без смертей может быть любого цвета.
- Умер при включённом заражении — сразу стал зелёным.
- Во время заморозки смерти и килы не считаются, поэтому новых
  заражённых нет.
- Режим сохраняется после рестарта сервера.

## Заморозка

```text
/deadcount freeze on
/deadcount freeze off
/deadcount freeze in 10m
/deadcount freeze for 30m
/deadcount freeze cancel
/deadcount freeze status
```

- `on` — новые смерти и килы **не считаются**.
- `off` — снова считаются.
- `in <время>` — заморозка автоматически через указанное время.
- `for <время>` — заморозить сейчас и разморозить через указанное время.
- `cancel` — отменить запланированный таймер, не меняя текущее состояние.
- Время: `30s`, `10m`, `2h`, `1d`. Без единицы — минуты.

Состояние и таймеры переживают рестарт сервера. Если сервер был выключен,
а таймер истёк — состояние применится при следующем запуске.

## Сброс

Только админ (`server`):

```text
/deadcount reset Vasya
/deadcount reset all
```

Сбрасываются и смерти, и килы. Сброс работает и для офлайн-игрока, если
он есть в статистике. Цвета при сбросе не трогаются.

## Установка

В сборке Doom-like мод уже лежит внутри папки сборки:

```text
doom-like/deadcount/
```

Достаточно добавить в `worlds/<мир>/world.mt`:

```ini
load_mod_deadcount = true
```

или включить **Deadcount** в списке модов мира. Для тестовых миров
используется явный путь:

```ini
load_mod_deadcount = mods/doom-like/deadcount
```

Если нужен отдельный мод вне сборки:

```bash
cp -r deadcount <проект>/minetest/mods/deadcount
```

Для сервера — скопировать `doom-like` целиком в
`server/minetest/mods/doom-like` и добавить ту же строку в `world.mt`
серверного мира.

## Настройки

В `minetest.conf`:

```ini
deadcount_hud = true
deadcount_max_rows = 10
deadcount_name_width = 18
deadcount_map_y = 0.30
deadcount_margin = 8
deadcount_neutral_color = #E0E0E0
deadcount_infected_color = #55FF55
```

- `deadcount_hud` — показывать HUD. Если выключить, `/deaths` продолжает
  работать. Режим `none` тоже скрывает HUD.
- `deadcount_max_rows` — сколько строк показывать в HUD; `0` — всех.
- `deadcount_name_width` — ширина колонки ника.
- `deadcount_map_y` — на какой доле высоты экрана начинается HUD
  под миникартой. Если миникарта больше/меньше обычной, можно подвинуть.
- `deadcount_margin` — отступ от края экрана в пикселях.
- `deadcount_neutral_color` — цвет ников без команды.
- `deadcount_infected_color` — цвет заражённых.

Настройки читаются при запуске мира.

## Сохранение

Смерти, килы, цвета, режим показа, режим заражения и заморозка хранятся
в `core.get_mod_storage()` мира. Перезаход игрока и рестарт сервера
ничего не сбрасывают. При переносе мира статистика переносится вместе
с ним.

Счёт начинается с момента включения мода — прошлые смерти и килы не
восстановить.
