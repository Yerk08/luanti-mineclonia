# Сборка Doom-like

Модпак для Mineclonia (Luanti). Внутри:

| Папка | Что это |
|---|---|
| `rifles/` | снаряд и взрывы для Бабахи; старые стволы без крафта и креатива |
| `accuracy/` | библиотека, обязательная для `rifles` |
| `sharp_map/` | полноэкранная карта, миникарта и точки-метки |
| `sharp_inventory/` | тёмный инвентарь и автосортировка для Mineclonia |
| `ambience/` | звуки окружения, воды и пещер |
| `vein_miner/` | добыча всей жилы за раз (шифт + копание) |
| `doomlike/` | кастомный мод: скорость, Бабаха с HUD перезарядки, стартовый набор, сытость, больше монстров |
| `nightvision/` | отдельный мод: команда `/nightvision` включает и выключает ночное зрение |
| `doomspawn/` | отдельный мод: случайный спавн в радиусе и неуязвимость после спавна |
| `deadcount/` | отдельный мод: смерти/килы, HUD, цвета-команды, заражение и заморозка |
| `hidenicks/` | отдельный мод: ники над головой, цветные ники и метки только для своих |

## Куда положить

Сборка должна лежать **целиком одной папкой** внутри `mods`:

- на ноуте: `<проект>/minetest/mods/doom-like`
- на сервере: `<проект>/server/minetest/mods/doom-like`

Из корня проекта:

```bash
# для ноута
mkdir -p minetest/mods
cp -r doom-like minetest/mods/

# для сервера
mkdir -p server/minetest/mods
cp -r doom-like server/minetest/mods/
```

Если папка уже скопирована и нужно обновить сборку, не создавай
`doom-like/doom-like`, а перезапиши содержимое:

```bash
cp -r doom-like/. minetest/mods/doom-like/
cp -r doom-like/. server/minetest/mods/doom-like/
```

В контейнере это будет `/data/mods/doom-like`. Папку `doom-like` не
переименовывай — внутри неё лежит `modpack.conf` с именем сборки.

## Как включить в мире

При создании мира в Luanti открой вкладку **«Моды» / Mods** и включи
сборку **Doom-like** (или все моды по отдельности).

Если мир уже создан, добавь в файл
`worlds/<имя_мира>/world.mt`:

```ini
load_mod_accuracy = true
load_mod_ambience = true
load_mod_rifles = true
load_mod_sharp_inventory = true
load_mod_sharp_map = true
load_mod_vein_miner = true
load_mod_doomlike = true
load_mod_nightvision = true
load_mod_doomspawn = true
load_mod_deadcount = true
load_mod_hidenicks = true
```

- Sharp Map открывается командой `/map`, миникарта — `/minimap`.
- Vein Miner работает при копании с зажатым Shift.
- Sharp Inventory добавляет тёмный интерфейс и автосортировку.

## Настройки кастомного мода

В `minetest.conf` (клиента или сервера):

```ini
doomlike_speed_multiplier = 1.6
doomlike_jump_multiplier = 1.4
doomlike_mob_cap_multiplier = 1.5
doomlike_babaha_reload = 3.0
doomlike_babaha_damage = 40
doomlike_babaha_speed = 40
```

- `doomlike_speed_multiplier` — множитель скорости ходьбы.
- `doomlike_jump_multiplier` — множитель высоты прыжка.
- `doomlike_mob_cap_multiplier` — во сколько раз поднять лимит монстров
  (`0` — выключить). Меняется на ходу командой `/mobcap <0-10>`.
- `doomlike_babaha_reload` — перезарядка Бабахи, секунды (3.0).
- `doomlike_babaha_damage` — прямой урон Бабахи (40).
- `doomlike_babaha_speed` — скорость снаряда Бабахи (40).

Стартовый набор: **Бабаха** (`doomlike:babaha`), полный сет кольчуги
(сразу надет), стак строительных лесов, стак факелов в левой руке и
железная кирка. Glock, вода, булыжник, выбор оружия и `/weapon` убраны.

Бабаха — единственное оружие:
- прямой снаряд без разброса и гравитации;
- 40 прямого урона + взрыв силой 4;
- блоки разрушает, но дропа не оставляет;
- свой урон от взрыва остаётся;
- патроны бесконечные, в инвентаре их нет;
- перезарядка **3 секунды** идёт, только пока Бабаха в руке. Переключился
  на другой предмет — прогресс сбрасывается в ноль, вернулся — начинай
  заново. На HUD круг работает как прицел, а после выстрела заполняется
  по 32 секторам (обновление 6 раз в секунду).

Сытость всегда держится на 20 — голод не мешает. При смерти все
предметы выпадают; после респавна набор выдаётся заново.

Night Vision вынесен в отдельный мод `nightvision`:
`/nightvision` или `/nv` — включить/выключить. Админ может запретить
команду всем через `/nightvision forbid`; зелья Night Vision при этом
продолжают работать. Мод меняет и эффект неба, и клиентскую кривую
освещения, поэтому ночное зрение работает **в пещерах и шахтах**, а не
только ночью на поверхности. Если мод не нужен, просто не включай
`load_mod_nightvision` в мире.

Спавн — отдельный мод `doomspawn`:
- при входе/респавне **5 секунд неуязвимости** (настраивается);
- без кровати — **телепорт высоко в воздух** в случайную точку
  в радиусе **50** блоков от мирового спавна (настраивается, до 1000);
- работает одинаково во всех мирах, независимо от подробного спавна
  Mineclonia;
- с кроватью/якорем — спавн у них, как обычно;
- после воздушного телепорта — **10 секунд без урона от падения**
  (настраивается).

Админские команды:

```text
/doomspawn status
/doomspawn on
/doomspawn off
/doomspawn radius 50
/doomspawn invuln 5
/doomspawn fall 10
```

`radius` — 0–1000 (0 = без разброса; большие значения сильно нагружают
генерацию), `invuln` — 0–60 секунд (0 = без защиты), `fall` — 0–60
секунд защиты от урона падением (0 = без защиты). `on`/`off` полностью
включает или выключает воздушный спавн, щит и защиту от падения.
Настройки глобальные для мира и сохраняются.
Если мод не нужен — не включай `load_mod_doomspawn`.

Deadcount — отдельный мод внутри сборки (`deadcount/`):
- HUD под миникартой: смерти **или** килы, одна колонка;
- `/deadcount mode deaths|kills|none`;
- `/deaths`, `/team`, `/deadcount ...`;
- цвета ников = команды: одинаковый явный цвет не даёт кил друг другу;
- нейтральные (без цвета) — FFA, килы между ними считаются;
- самоубийство — не кил; смерти от мобов/падения килов не дают;
- режим заражения, заморозка и таймеры остаются;
- статистика хранится в мире и переживает рестарт.

Подробности — в `deadcount/README.md`. Если не нужен, не включай
`load_mod_deadcount`.

Hidenicks — отдельный мод внутри сборки (`hidenicks/`):
- `/hidenicks none` — стандартные ники;
- `/hidenicks all` — ники видны и подкрашены цветом команды;
- `/hidenicks hidden` — ники скрыты, меток нет;
- `/hidenicks team` — ники скрыты, свои видят метки своих через стены;
- `/hidenicks status`;
- алиасы: `show`, `hide`, `off`, `teams`.

В `none`, `all` и `hidden` HUD-метки не создаются. В `team` метки
получают только игроки одного явно выбранного цвета из deadcount.
Подробности — в `hidenicks/README.md`.
