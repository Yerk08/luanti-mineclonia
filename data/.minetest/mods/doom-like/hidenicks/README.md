# Hidenicks

Отдельный мод для сборки Doom-like: управляет никами над головой.

- В `none` — всё стандартно.
- В `all` — ники видны и подкрашены цветом команды.
- В `hidden` — ники скрыты у всех, HUD-меток нет.
- В `team` — ники скрыты, но каждый игрок видит **HUD-метки только на своих**
  через стены.

Цвет команды берётся из deadcount: одинаковый явно выбранный цвет = одна
команда. Игроки без цвета не имеют команды — в `team` они не видят никого
и их никто не видит.

## Команды

Только админ (`server`):

```text
/hidenicks none
/hidenicks all
/hidenicks hidden
/hidenicks team
/hidenicks status
```

Алиасы:

```text
/hidenicks show   -- all
/hidenicks hide   -- hidden
/hidenicks off    -- none
/hidenicks teams  -- team
```

Режим общий для мира и сохраняется в `core.get_mod_storage()`.
По умолчанию — `none` (стандартные ники).

## Как работает

- `none`: нативные ники видны, цвет стандартный.
- `all`: нативные ники видны; цвет текста берётся из цвета команды
  (нейтральные — серые). HUD-меток нет.
- `hidden`: у нативных ников прозрачность 0. HUD-меток нет.
- `team`: нативные ники скрыты; каждый игрок получает HUD-waypoint'ы
  на игроков своего цвета. Метки обновляются 5 раз в секунду и видны
  через блоки.

В `none`, `all` и `hidden` HUD-метки не создаются вообще, поэтому
per-tick обновлений нет. В `all` раз в секунду обновляется только цвет
нативных ников, если игрок сменил команду.

## Ограничения

- Это не нативные ники: в `team` метка — HUD-waypoint, поэтому она видна
  через стены и не имеет такого же фона, как обычный ник.
- Список игроков (Tab) и deadcount HUD по-прежнему показывают имена —
  мод меняет только отображение над головой.
- В `team` игрок без выбранного цвета не видит никого. Перед командным
  матчем цвета нужно раздать.

## Зависимости

Нужен мод `deadcount` — из него берутся цвета команд.
