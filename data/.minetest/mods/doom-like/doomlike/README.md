# Doom-like (кастомный мод)

Мод для сборки Doom-like под Mineclonia. Единственное оружие — **Бабаха**
(`doomlike:babaha`), сделанная на основе M79.

## Что делает

1. **Скорость и прыжок** — множители `1.6` и `1.4` по умолчанию.
2. **Стартовый набор** — при первом входе и после респавна выдаёт:
   - Бабаху;
   - полный сет кольчуги (`mcl_armor:*_chain`) — сразу надевается;
   - стак строительных лесов (`mcl_bamboo:scaffolding`);
   - стак факелов (`mcl_torches:torch`) в левую руку;
   - железную кирку (`mcl_tools:pick_iron`).
   При смерти все предметы выпадают; после респавна набор выдаётся заново.
3. **Сытость** — всегда держится на 20, голод не мешает.
4. **Больше монстров** — поднимает лимит монстров Mineclonia
   (`mcl_mobs.spawn_categories.monster`) в `1.5` раза. Множитель можно
   менять командой `/mobcap` без рестарта.

Glock, выбор оружия и `/weapon` убраны. Патроны для Бабахи не нужны —
они не занимают инвентарь.

## Бабаха

- Прямой снаряд, без разброса и гравитации.
- **40** прямого урона + взрыв силой **4**.
- Взрыв ломает блоки, но не оставляет дропа.
- Свой урон от взрыва остаётся: в упор стрелять опасно.
- **Бесконечные патроны** — ограничение только перезарядка.
- **Перезарядка 3 секунды** идёт, пока Бабаха в руке:
  - выстрелил — круг на HUD начинает заполняться;
  - переключился на другой предмет — прогресс сбрасывается в ноль;
  - вернулся — перезарядка начинается заново;
  - заполнился — круг снова работает как прицел.
- HUD: 32 сектора, обновление 6 раз в секунду. Ванильный крестик
  на время Бабахи скрывается.

## Настройки в `minetest.conf`

```ini
doomlike_speed_multiplier = 1.6
doomlike_jump_multiplier = 1.4
doomlike_mob_cap_multiplier = 1.5
doomlike_babaha_reload = 3.0
doomlike_babaha_damage = 40
doomlike_babaha_speed = 40
```

- `doomlike_babaha_reload` — секунды перезарядки (0.5–10).
- `doomlike_babaha_damage` — прямой урон (1–200).
- `doomlike_babaha_speed` — скорость снаряда (10–200).

## Лимит монстров

Только админ (`server`):

```text
/mobcap status
/mobcap 1.5
/mobcap 0
```

- `1.0` — как в обычной Mineclonia.
- `1.5` — текущее значение по умолчанию.
- `0` — монстры не спавнятся.
- Значение сохраняется в мире и переживает рестарт.

## Старые стволы

Остальные предметы `rifles` остаются зарегистрированными, чтобы старые
пушки в мирах не превратились в `unknown item`. Но:

- их нельзя скрафтить;
- они спрятаны из креатива;
- старые kit-предметы (Glock, патроны, булыжник, ведро и другие стволы)
  удаляются при входе.

Night Vision вынесен в отдельный мод `nightvision`: команда
`/nightvision` (и `/nv`). Админ может запретить её всем через
`/nightvision forbid`; зелья Night Vision при этом работают.
