# Doom-like (кастомный мод)

Мод для сборки Doom-like под Mineclonia.

Что делает:

1. **Скорость и прыжок** — множители `1.6` и `1.4` по умолчанию.
2. **Стартовый набор** — при первом входе и после респавна выдаёт:
   - пистолет `Glock 17` (`rifles:glock17`) — он есть у всех по умолчанию;
   - основное оружие на выбор: `SPAS-12` (30 урона),
     `Jackhammer` (авто-дробовик, 40 урона), `M79` (гранатомёт,
     по умолчанию), `RPG-7` (ракетница, взрыв 3) или `AK-47`
     (автомат, 30 патронов);
   - 3 ручные гранаты (`rifles:grenade`) отдельными стаками (`stack_max = 1`);
   - 5 золотых яблок (`mcl_core:apple_gold`);
   - ведро воды (`mcl_buckets:bucket_water`);
   - железную кирку (`mcl_tools:pick_iron`);
   - полный сет кольчуги (`mcl_armor:*_chain`) — сразу надевается;
   - «Кольчужная каска с фонариком» — зачарованный кольчужный шлем
     с бесконечным Night Vision; лежит в инвентаре, надень его сам.
     Пока каска надета — эффект активен, после снятия гаснет через
     пару секунд (зелье Night Vision при этом не затрагивается);
   - стак факелов (`mcl_torches:torch`) в левую руку.
   Патроны для выбранного оружия и Glock автоматически пополняются
   раз в 10 секунд. Гранаты и золотые яблоки конечны.
   Все предметы набора помечаются в метаданных и **не выпадают при смерти**.
3. **Выбор оружия** — меню при первом входе и команда `/weapon`
   для смены основного оружия.
4. **Сытость** — всегда держится на 20, голод не мешает.
5. **Больше монстров** — удваивает лимит монстров Mineclonia
   (`mcl_mobs.spawn_categories.monster`).

Настройки в `minetest.conf`:

```
doomlike_speed_multiplier = 1.6
doomlike_jump_multiplier = 1.4
doomlike_mob_cap_multiplier = 2.0
doomlike_shell_target = 50
doomlike_ammo_refill_interval = 10
```

Мод не изменяет `rifles` и `light_works` — только использует их предметы.
